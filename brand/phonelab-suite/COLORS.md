# PHONELAB SUITE — Color System

## Core

The family uses a neutral technical foundation so individual products can have their own accent.

Light: near-white background, white surfaces, near-black text, neutral muted text, light neutral borders.

Dark: near-black blue-neutral background, dark blue-neutral surfaces, near-white text, cool-grey muted text, low-opacity white borders.

# Growth layer · PhabLab mobile suite

The goal is not to force virality. Each app should make its usefulness visually obvious enough that a user naturally wants to show the result.

## Product rules

1. **Five-second comprehension.** The first screen must explain the action without a tutorial carousel.
2. **One visible transformation.** Every app needs a before/after, remote reaction, live number, match, ranking or full-screen change.
3. **No account before value.** Pairing and measurement work without registration.
4. **Share the result, not marketing.** Result sharing is useful by itself; branding stays small.
5. **Two-phone magic where relevant.** Pairing is a product feature, not a configuration page.
6. **Old-phone reuse.** SignMe and SensorLink explicitly turn a spare phone into useful hardware.
7. **Real captures only.** Store screenshots and social videos must show the actual app.
8. **No fake precision.** Acoustic, timing and sensor tools clearly label relative/approximate values where hardware clocks or sensors limit accuracy.
9. **Comfortable sound levels.** No app instructs users to generate excessively loud sounds.
10. **International by design.** Short English UI, icons and numbers first; store text can be localized independently.

## Store acquisition

- Apple: one default product page plus custom product pages for distinct intent clusters (creator/video, home/DIY, education/experiments). Deep-link each page to the relevant first action once universal links are enabled.
- Google Play: run store listing experiments on icon, first screenshot and short description one variable at a time.
- Do not make 16 identical store pages. Each app leads with its own transformation.
- Launch assets should be 6–10 second real-device clips: setup → action → surprising result.

## Cross-promotion

Cross-promotion is opt-in and subtle: a single “More pocket tools” entry in Settings/About after the user has completed an action. Never interrupt the first-run task with ads for another app.

## Paid model

Prefer a low-cost paid download or a free functional demo plus one-time unlock only if store conversion data proves the demo materially helps. Avoid subscriptions for these single-purpose tools.
